## 📱 How To Use

### Start Drawing
1. Tap anywhere on white canvas
2. Drag your finger to draw
3. Lift finger to finish line

### Change Color
1. Tap **🎨 Color** button
2. Select a color from palette
3. Panel auto-closes
4. Draw with new color

### Adjust Brush Size
1. Tap **● Size** button  
2. Choose: Thin, Medium, Thick, or Extra Thick
3. See visual preview
4. Tap **Done** or start drawing

### Use Rainbow Mode
1. Tap **🌈 Rainbow** button
2. Draw - colors shift automatically!
3. Creates psychedelic rainbow effects

### Erase Parts
1. Tap **⌫ Eraser** button
2. Draw over areas to erase
3. Eraser has larger size
4. Tap **✏️ Draw** to return to drawing

### Undo/Redo
- Tap **↶** to undo last stroke
- Tap **↷** to redo undone stroke
- Always available in top bar

### Save Your Art
1. Tap **☰ Menu** button
2. Tap **💾 Save Drawing**
3. Artwork saves to Photos
4. Success message appears

### Share Your Art
1. Tap **☰ Menu** button
2. Tap **📤 Share Drawing**
3. Choose app to share with
4. Send to friends!

### Clear Canvas
1. Tap **🗑 Clear** button
2. Confirm you want to clear
3. Canvas erases completely

### Start Fresh
1. Tap **☰ Menu** button
2. Tap **📄 New Drawing**
3. Choose to save current drawing
4. Canvas clears for new art

### Return to Menu
1. Tap **☰ Menu** button
2. Tap **🏠 Main Menu**
3. Returns to title screen

## 💡 Pro Tips

✨ **Rainbow Mode**: Great for backgrounds and abstract art!

✨ **Undo/Redo**: Don't be afraid to experiment - you can always undo

✨ **Eraser**: Works like a thick white brush

✨ **Layer Strategy**: Draw big shapes first, details last

✨ **Color Combinations**: Try complementary colors (red/green, blue/orange)

✨ **Smooth Lines**: Draw slowly for smooth curves

✨ **Quick Actions**: Top bar has your most-used features

✨ **Panel Close**: Start drawing to auto-close panels

## 🖌 Brush Sizes

Choose from 4 brush sizes:
- **Thin (2pt)**: Fine details, signatures
- **Medium (5pt)**: Default, most versatile
- **Thick (10pt)**: Bold lines, fills
- **Extra Thick (15pt)**: Large areas, backgrounds

## ⚙️ Settings

Currently the app has these defaults:
- **Mode**: Rainbow (colors shift automatically)
- **Brush Size**: Medium (5pt)
- **Canvas**: White background
- **Orientation**: Any (portrait or landscape)

## 🆘 Troubleshooting

**Can't save to Photos?**
- Check Settings > Privacy > Photos
- Allow Color Line Draw access

**Button not working?**
- Make sure you're tapping (not drawing)
- Try tapping in center of button

**Lost my drawing?**
- Check Photos app
- If not saved, drawing is lost
- Always save before exiting

**Want to change color?**
- Tap 🎨 Color button
- Or use 🌈 Rainbow mode

**Eraser not working?**
- Make sure ⌫ Eraser is selected (blue highlight)
- Eraser uses white color on white background
